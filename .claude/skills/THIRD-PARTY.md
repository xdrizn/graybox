# Third-party skill sources

`grilling`, `diagnosing-bugs`, `tdd`, `handoff` and `wait-what` are adapted for Graybox from
[mattpocock/skills](https://github.com/mattpocock/skills) (MIT). Each adapted file says so in its footer.
Skipped on purpose: issue-tracker / ticket / spec flows (`to-spec`, `to-tickets`, `implement*`,
`triage`, `wayfinder`, `setup-*`), `pr` (we do not push or open PRs unless Adriel asks),
`code-review` (Claude Code already has one), `domain-modeling` / `codebase-design` (need a GLOSSARY
and ADRs this repo does not have), `retro`, `research`, `teach`, `wizard`, `prototype`.
