Adriel did not understand your last message. Re-explain it:

- Brazilian Portuguese, short sentences, one idea per sentence. No Rust or engine words.
- Say first **what he will see or be able to do**, then why, then what you need from him (if anything).
- Give one concrete example from the app (a button, a panel, a screen) instead of a definition.
- Use the same names the app shows on screen (menu and panel labels), not code names.
- End with a yes/no question only if a decision is needed.
